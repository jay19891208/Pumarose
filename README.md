# Puma Rose

**A breakfast that becomes a memory.**

> **Showcase repository.** The source code is private. This page describes the product.

![Puma Rose](screenshots/website.jpg)

## What it is
Brand and e-commerce website for a surprise-breakfast gift business in Wichita, Kansas.

- Step-by-step gift box builder
- Rush delivery logic and delivery-area check
- Corporate (B2B) orders, gallery and contact
- Checkout ready for payment integrations
- English and Spanish
